# Code of conduct

This project is a maintainer tool. Discussion stays on the software.

- Critique changes, not people.
- Do not post other people's private issues, credentials, or documentation excerpts in public threads.
- Assume good faith, and stop when someone asks you to stop.
- Harassment, slurs, and sexual attention are not welcome.

Maintainers of a given fork may hide comments or block accounts that break these rules. If you run a public fork, name a contact for reports in that fork's README.
